# Помощник ответов для системы тестирования

PowerShell-скрипт для Windows: выбираете тему, загружаете Word с вопросами/ответами, копируете вопрос из системы тестирования — скрипт находит правильный ответ.

## Темы

1. Русский язык  
2. АТО и ТК  
3. Экспертиза  

Список тем и пути к файлам настраиваются в `config.json`.

## Установка на своём ПК

1. Скопируйте папку `exam-assistant` на компьютер.
2. Положите свои `.docx` в `answers/` (или поправьте пути в `config.json`).
3. Откройте PowerShell и выполните:

```powershell
cd путь\к\exam-assistant
Set-ExecutionPolicy -Scope Process Bypass
.\Start.ps1
```

Желательно установленный Microsoft Word (чтение через COM точнее). Без Word скрипт читает `.docx` как ZIP/XML.

## Как пользоваться на тесте

1. Запустите `Start.ps1`, выберите тему.
2. В системе тестирования **выделите текст вопроса** и нажмите **Ctrl+C**.
3. В окне помощника нажмите **F8** (или Enter и вставьте вопрос).
4. Скрипт покажет лучшее совпадение и **скопирует ответ в буфер** — вставьте/отметьте его в тесте.
5. Клавиша **Q** — вернуться к выбору темы.

Полный автоклик по вариантам в чужой программе не делается: у разных систем тестирования разный интерфейс, а копирование вопроса + показ ответа работает везде.

## Если совпадений мало

- Копируйте вопрос целиком, без лишнего текста интерфейса.
- В `config.json` можно снизить `match.minScore` (например до `0.45`).
- Проверьте, что парсер видит ваши пары: при загрузке темы в консоли пишется «найдено пар вопрос/ответ».
