# Файлы с ответами

Положите сюда свои Word-документы (`.docx`) и укажите имена в `../config.json`.

Сейчас ожидаются:

| Тема | Файл |
|------|------|
| Русский язык | `russian.docx` |
| АТО и ТК | `ato-tk.docx` |
| Экспертиза | `expertise.docx` |

В репозитории лежат **примеры** с несколькими учебными вопросами — замените их своими полными списками.

## Рекомендуемый формат в Word

```
Вопрос 1: Текст вопроса?
а) вариант один
б) вариант два
в) вариант три
Ответ: б) вариант два

Вопрос 2: Другой вопрос?
Ответ: краткий правильный ответ
```

Также понимаются нумерованные вопросы вида `12. Текст вопроса?` и пометка верного варианта символами `+` / `*` / `✓`.
