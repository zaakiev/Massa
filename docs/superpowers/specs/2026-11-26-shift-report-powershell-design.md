# Ежедневный отчёт смены ММТП — дизайн (черновик)

**Статус:** согласовано по разделам, финальное подтверждение отложено — продолжить, когда инспектор будет на посту.  
**Дата:** 2026-11-26  
**Макеты:** `docs/mockups/`

## Цель

Автоматизировать заполнение ежедневного отчёта дежурной смены таможенного поста «Морской торговый порт Махачкала» по образцу печатных бланков (2 листа).

## Решения

| Тема | Выбор |
|------|--------|
| Платформа | **PowerShell + Windows Forms** (без `.exe`) |
| Файл отчёта | Один общий `.xlsx` на сетевом диске; смены дополняют его |
| Сменные таблицы | Перезапись под текущую смену |
| Накопительные поля | Сохраняются (простой с начала года, ПТД нарастающим и т.п.) |
| Смена | 09:00 → 09:00; автоопределение + ручной переключатель |
| Роли | Старт: **Суда** или **ВХ**; можно сменить без перезапуска |
| Справочники | Лист «Справочники» + добавление значения «на лету» в форме |
| Одновременная запись | В v1 не делаем (простая запись) |
| Пустой проход | Если инспектор ничего не изменил — **Excel не трогаем** |
| ВХ срок | «Статус на ВХ» = день внесения **+1**; «Истеч. срока» = эта дата **+4 месяца** |
| Лес / калий | Блок **«Иные товары на ПЗТК»** (не отдельная спецлогика названия) |

## Архитектура

```
ОтчетСмены.ps1 (+ модули .ps1)
        │
        │  WinForms (как на макетах)
        ▼
Общий .xlsx на сетевом диске
  • Суда
  • ВХ
  • Справочники
```

- Запись в Excel через COM (нужен установленный Excel на ПК).
- Путь к файлу и последняя смена — в локальных настройках рядом со скриптом / в профиле пользователя.
- Запуск: ярлык или `powershell -File ОтчетСмены.ps1` с общего диска.

## Экраны

1. **Старт** — путь к файлу, период смены, кнопки «Суда» / «ВХ».
2. **Суда (лист 1)** — блоки: Прибытие, Убытие, Суда на рейде, Ожидание убытия, Простой, Размещение на причалах; накопительный простой.
3. **ВХ (лист 2)** — Временное хранение, С борта (ПТД), Операции на причалах, Итоги ДО1/ДО2/ТН/ДТ-ИМ/ЭК, Иные товары на ПЗТК.
4. **Диалог строки** — поля блока, ComboBox из справочника, «+ новое».
5. **Нет изменений** — сообщение, файл не перезаписывается.

Макеты PNG: `01-start` … `06-no-changes` в `docs/mockups/`.

## Правила данных

- Обязательные поля пустые → ОК в форме недоступен / ошибка.
- Файл занят / нет доступа → понятное сообщение, без тихой потери данных.
- № п/п — по порядку в блоке.
- Сохранение пишет только блоки **текущего** направления при наличии изменений.

## Вне скоупа v1

- Одновременное редактирование двумя инспекторами.
- Отдельный скомпилированный `.exe`.
- Полная замена печати Excel (печать остаётся из книги).

## Как продолжить

1. Подтвердить финал дизайна на посту (сверить блоки с живым бланком).
2. Написать план реализации (`writing-plans`).
3. Сверстать шаблон Excel + скрипты PowerShell/WinForms по макетам.
4. Проверка на общем диске: суда → ВХ → пустой проход → автосрок ВХ.
